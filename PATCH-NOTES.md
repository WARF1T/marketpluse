# Исправление статуса рынка и ошибок API

- Убраны автоматические демо-цены, случайные изменения цен и алерты на них.
- Карточка предмета при отказе рынка не подставляет модельную статистику.
- График цены показывается только при наличии истории реальных сделок.
- Успешная проверка Worker больше не означает «рынок онлайн».
- Ошибки каталога и цены содержат upstreamStatus; глубокая диагностика — marketStatus.
- HTTP 403 и 429 кэшируются на 15 секунд; повтор без Platform/Language удалён.
- Имя Worker в wrangler.jsonc изменено на marketpluse, согласно адресу сайта.

Не устранено: запрет HTTP 403 со стороны warframe.market. Эта версия не обходит блокировки и не гарантирует восстановление доступа. После деплоя проверь /api/health?deep=1. Статические справочники реликвий, методов фарма и рейтинга не являются live-данными рынка. Деплой из этого чата не выполнялся.
